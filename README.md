# PanenHub - Ekosistem Rantai Pasok Pangan Segar Nusantara

PanenHub adalah platform digital rantai dingin terintegrasi yang menghubungkan kelompok tani kebun dan nelayan pesisir langsung dengan mitra warung tetangga dan konsumen nusantara.

## Fitur Utama

- **Multi-Role Seamless Gateway**: Layar masuk terpadu untuk Konsumen, Mitra Produsen (Petani & Nelayan), dan Mitra Warung.
- **Konsumen & Tokopedia-Style Storefront**: Belanja sayur, lauk, dan buah segar petik subuh dengan opsi ambil di warung tetangga (bebas ongkir).
- **Portal Mitra Petani**: Manajemen kuota permintaan kota, monitoring Cold Pod desa surya (0–4°C), dan pencairan T+0 seketika.
- **Portal Mitra Nelayan**: Pengelolaan tangkapan laut standar sashimi, Slurry IcePod dermaga pelabuhan (0.8°C), serta proteksi anti-ijon.
- **Kasir & Drop-Point Mitra Warung**: Validasi PIN tiket digital 4 digit dan sistem komisi tunai Rp 2.000 per paket.

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

## Deploy ke Vercel

```bash
npm run build
```
Otomatis terhubung dengan domain `panenhub.vercel.app`.
